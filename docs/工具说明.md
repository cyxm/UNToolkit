## 框架工具

### pnpm

本项目使用[pnpm](https://pnpm.io/)作为包管理器。

1. 安装pnpm:

   ```bash
   npm install -g pnpm
   ```

2. 安装依赖:

   ```bash
   pnpm install
   ```

3. 常用命令:
   - `pnpm add <package>` - 添加依赖
   - `pnpm remove <package>` - 移除依赖
   - `pnpm run <script>` - 运行脚本

本项目使用pnpm workspace功能管理多个子包，根目录下的`pnpm-workspace.yaml`定义了工作区配置。

### npm-check-updates (ncu)

[npm-check-updates](https://github.com/raineorshine/npm-check-updates)是一个用于更新package.json依赖的工具。

1. 安装ncu:

   ```bash
   npm install -g npm-check-updates
   ```

2. 检查可更新的依赖:

   ```bash
   ncu
   ```

3. 更新package.json:

   ```bash
   ncu -u
   ```

4. 更新后安装新版本:

   ```bash
   pnpm install
   ```

建议在更新依赖前先运行测试确保项目稳定性。

### Turbo

[Turbo](https://turbo.build/)是一个高性能的构建系统，用于优化monorepo项目的开发体验。

1. 安装Turbo:

   ```bash
   npm install -g turbo
   ```

2. 常用命令:

   ```bash
   turbo build   # 运行构建
   turbo dev     # 启动开发服务器
   turbo test    # 运行测试
   ```

3. 项目配置:
   - 根目录下的`turbo.json`定义了构建管道和任务依赖
   - 与pnpm workspace配合使用，优化monorepo中的任务执行

### waiton

[waiton](https://github.com/jeffbski/wait-on)是一个命令行工具，用于等待服务可用后再执行后续命令。

1. 安装waiton:

   ```bash
   npm install -g wait-on
   ```

2. 基本用法:

   ```bash
   wait-on http://localhost:8080 && echo "Server is ready"
   ```

3. 常用选项:
   - `-t` 超时时间(毫秒)
   - `-i` 轮询间隔(毫秒)
   - `-v` 详细输出

4. 项目中使用:
   - 可用于等待后端API服务启动后再启动前端开发服务器
   - 示例配置可参考项目中的`package.json`脚本
